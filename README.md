# Assignment 5

Lavet af Sandra, Christian og Sigurd.

Et React-projekt med TypeScript og Vite, der søger efter personer via The Movie Database (TMDB). Appen søger efter Kubrick ved opstart og viser resultaterne i browserens konsol.

## Kom i gang

Opret `.env.local` i projektmappen med `VITE_TMDB_API_KEY=din_api_nøgle`.

```sh
npm install
npm run dev
```
